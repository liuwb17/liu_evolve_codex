两个实验分别从同一人工 seed 开始，真实模型实验没有以离线优胜代码作初始程序。训练数据为 12 个题面分布合成样例加 1 个官方样例；验证和留出各 12 个合成样例。合成输入不是官方 Rust seed 的逐例复现。

真实模型调用了正式 DeepSeek Chat Completions 服务；`/models` 返回 `deepseek-flash` 与 `deepseek-v4-pro`。没有使用伪造响应或将离线结果冒充模型结果。9 次模型请求含 3 次无效响应；修复过程完整保留。服务端账本共记录 46,885 input tokens、17,226 completion tokens、64,111 total tokens。未以估算代替实际费用账单。

本次真实搜索耗时约 129.9 秒（不包括环境安装与随后独立交叉验证）。所有候选在 Docker 中执行。内部留出集在选出程序后冻结再读取，12 例全部合法。留出提升 0.069704，对应描述性配对 bootstrap 95% 区间 [0.045178, 0.098448]；单搜索 seed 不足以证明框架优于其他 AAD 方法。

离线模式迭代数更多且采用领域手写变异规则，因此表中两行不是公平的模型/方法对比。
