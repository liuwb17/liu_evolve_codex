第三次参数化返回有效候选 `3b5a13d377b3c5734f7b910955974edfaf87cae6d39de75299a179841688b259`，默认训练均分 986,551,137.525，原父代为 986,635,777.525。人工差异检查确认六个参数均用于原有搜索机制，未暴露总时限、随机种子或题目常量。模型把贪心概率抽样从 `rng()%100<70` 改成千分比阈值，改变了具体随机轨迹，因此这不是严格语义等价重构；仍作为独立候选实测，不将分数差异全部解释为运行噪声。未手工修改求解器代码。

这不是人工补写 AHC001 求解算法。初始算法和结构变异仍来自本次 LLM 谱系；模型从自己的当前最佳程序中选择参数、范围与默认值，控制器使用通用差分进化选择数值组合。

## 当前预算分配

Flash 已使用 6 次生成请求；Pro 常规阶段上限暂设 54 次，随后最多预留 4 次用于参数化、参数块安装及必要修复。因此总计仍最多 64 次模型生成请求。只读 `/models` 连接检查不属于此生成请求计数，实际账单不能仅按请求次数推算。若预留请求未用完，可在总上限内继续普通演化；没有明确授权不得超过总上限。

一次只能运行一个写入同一实验目录的控制器。

```bash
# 常规阶段结束后，生成并检查参数接口（最多两次生成/修复）
python scripts/v3_parameter_search.py --run-dir runs/v3_pro_fromscratch --calls 58 --variants 64 --ask-key --prepare-only
# 确认参数范围不包含计时上限、随机种子、输入数据或题目常量，再继续
python scripts/v3_parameter_search.py --run-dir runs/v3_pro_fromscratch --calls 58 --variants 64 --ask-key
```

`--calls` 为该 Pro 运行目录的累计生成请求上限，不是新增次数。当前阶段结束后仍未冻结，也未读取验证成绩或私有实例。

## 模型接口与评测

模型被要求最多暴露六个重要参数；解析器允许 1–8 个。每项明确名称、整数/浮点、线性/对数尺度、上下界和原默认值。`argv[1]` 仍是搜索时间，额外参数按声明顺序传入。要求维持原算法默认行为，所有组合均须遵守原计时与合法性约束。参数化后先做六例短预算合法性检查及完整四十例训练评测；默认均分比原程序下降超过 2M 则要求修复。还会在十二例上检查“显式传入默认参数”与普通默认运行的均分差异不超过 2M，防止参数接口错位。这些是经验检查，不是语义等价证明。

本地最多评测 64 组不重复参数，包括默认组合。使用 DE/rand/1/bin，随机种子 644001，差分系数 0.7、交叉率 0.85，种群大小 8–16。数值空间耗尽可提前结束。这些是通用控制器规则，不是矩形构造或邻域算法。

每组先在既定十二个公开训练筛选实例上运行完整 4.8 秒预算；按均分取前四，另保留默认组合，在全部四十例及六例短预算上复核。任意非法输出或超时均不合格。每例仍为 1 CPU、512 MiB、最多六例并行；候选硬限 4.95 秒，Docker 启停不计入候选时间。专用参数计时器与普通计时器具有相同限制，参数向量参与缓存键。

只在非默认组合的四十例均分超过原父代至少 0.05M 时尝试安装。该阈值只用于节约生成请求，不是显著性检验。数值试验分数不是最终独立程序的成绩，安装后必须重新计分。

## 参数块来源与安装

模型生成参数化完整程序时，按统一接口格式声明一个 `AAD_PARAMETERS_BEGIN` / `AAD_PARAMETERS_END` 区域。此区域只含 `constexpr` 数值默认值。控制器不会手写替代算法。

选定数值后，再请求模型输出对应参数块，最多尝试两次。解析器验证声明类型、顺序、上下界、目标数值和无额外代码，然后用该模型输出替换父代的参数区域。区域外源码逐字保留。最终程序无须额外参数即可使用选定默认值，可直接按普通流程选型和终测。

来源审计区分两类，而不是声称组装后的全文必定来自单条 API 响应：

- `full-program`：完整源码与单条 API 响应相同。
- `parameter-block`：完整源码等于本实验已有父代，加上模型返回的受限参数块；审计重新组装、核对哈希，并核对实际请求中的父代、参数描述和选定数值。

`all_sources_match_audited_origin` 检查两类来源。若存在参数块，`all_sources_match_api` 为 false 是预期的严格字面含义，不表示审计失败。人工贡献为控制器、参数搜索、接口约束与验证；参数数值由本地搜索选择，不能归功于模型独自发现。

所有试验、失败及阶段状态保存在运行目录 `numeric_search/`。支持检查点续跑和 `STOP_AFTER_CURRENT` 边界停止。开始公开验证后，数值层同样禁止继续开发；不会读取一千个私有实例。
