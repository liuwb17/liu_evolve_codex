# v5：恢复结构探索，限制无效交叉，闭合性能反馈

## v4复盘：证据与推断分开

v4最终私有均分955.582938M，不如Flash v3的986.446533M。v4不是成功升级。

直接观察：

1. 最终程序平均进程耗时0.165693秒、最长0.785418秒，预算为4.8秒。源码中坐标下降 `if(!improved) break`，后处理又受 `pass < 6` 限制。仅提高迭代上限不保证有收益；问题是搜索抵达局部终点后没有有效继续探索。
2. 133个实验事件中70个为交叉，其中49个评测后未晋升。旧UCB使用全历史收益、没有近期配额，早期收益可以长期影响调度；实际搜索偏向交叉。
3. v4最高单次训练均分957.782M的候选在第二次复测出现矩形重叠。排除该候选是必要的，不能为了高分跳过合法性。v4只对最初评测非法安排修复，复测非法未回流，反馈链存在缺口。
4. 256次请求产生114份代码。设计和实现分开调用、实现关闭thinking，且仅允许一个连续编辑。输出完成率提高不代表算法设计更好。

推断（尚无消融证明）：设计与实现分离、单位置修改、过早保守晋升、轮流投资低质量谱系，可能共同抑制了结构改进。不能将v4失败完全归因于某一项，更不能将种子/单次随机运行差异排除在外。

## 已实现的v5变化

- **每份提案一次请求**：完整代码或协调编辑，统一使用Flash低强度thinking、65536输出上限。完整源码不装入大型JSON，只要求简短假设注释和完成标记；不再单独花一次请求写设计。失败也计次，不拼接截断内容。
- **适当放宽修改范围**：局部改进可修改最多6个相关位置；所有锚点必须是原父代的唯一且不重叠子串，绑定父代哈希。结构重设计、运行预算改进、交叉和修复可返回完整程序。
- **有界调度**：八槽轮转含局部改进、两次结构重设计、运行预算改进、一次交叉及一次独立重启。最近8个实验最多1次交叉；没有逐例优势供体则不做交叉。某算子近期3次无明显父代收益时改为结构探索，避免历史奖励长期垄断预算。
- **利用耗时诊断，不奖励耗时**：对训练集比较0.6秒和4.8秒的同例分数，提供预算利用率、低分布局几何约束。父代平均运行不足2.4秒且成绩非接近满分时，周期性触发运行预算改进请求；明确禁止睡眠、空转及重复相同工作。框架不手写求解算法，也不强制每个程序耗满时间。
- **强父代优先与多样性档案**：按训练均分保留最多8个候选，同一独立初代谱系最多2份；大多数请求使用档案最高分，保留一部分多样性探索，不平均投入所有低分岛屿。
- **训练探索与最终选型分开**：合法程序全40例评测，有希望的程序和独立初代做3次独立缓存复测。训练换优要求重复均分提升>0.05M、至少2次重复方向为正，不要求跨实例bootstrap显著。最终验证仍要求>0.2M及保守配对检查，微小差异保留稳定优胜者。
- **复测失败进入修复**：任一次复测非法就排除候选，并把实际失败输入和输出送回模型；每次修复失败不递归无限修复。

这些是工程策略，不是统计显著性保证。原有私有1000例已被多轮观察，是固定已知基准，不再宣称研究层面的完全盲测。v5求解器仍从问题定义冷启动；不会把v3/v4代码、人类源码、私有输入或失败案例传给模型。

## 本次真实实验

沿用外部条件：`deepseek-flash`、最多256次生成请求、不额外限制总tokens；公共40训练/10验证；单例4.8秒搜索、4.95秒硬限、1 CPU/512 MiB、6并行，相同Docker镜像。设计协议已变，因此不是等token/等总计算量消融。

运行：`python -B scripts/v5_run_experiment.py`。目录 `runs/v5_flash_256_20260924`。自动完成训练、公开验证冻结、来源审计和 `runs/v5_flash_256_system_1000` 私有终测。官方种子和原版Rust工具沿用已核验的数据链；kusano复用此前同预算全量重测，逐例输入哈希校验。被冻结或进入最终选型后禁止继续开发。

测试：启动前66项测试通过，包含协调编辑重叠拒绝、交叉配额、同例时间对比、复测失败修复、单请求模拟全流程、模型来源审计。模拟结果不是算法成绩。真实效果需要本次实验完成才能回答。

入口：`scripts/v5_search.py`、`scripts/v5_run_experiment.py`；实现：`aad/v5_engine.py`、`aad/v5_policy.py`、`aad/v5_provider.py`。
